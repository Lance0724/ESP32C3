# EC11与温度标定技术规范

## 方案与现状
批准根目录计划作为参数与场景契约。现有ADC每秒采样，PWM每4ms通过Ticker执行；安装的ESP32 Ticker使用 `ESP_TIMER_TASK`，多个Ticker共享调度线程。编码旋转回调来自GPIO中断，不能执行OLED/Flash。校准安全监督能检测主循环停顿，但无法在整个ESP定时任务卡死时独立工作，仍需硬件保护。

## 设计决策
| 编号 | 需求/验收 | 内容与范围 |
| --- | --- | --- |
| DES-001 | REQ-001 / AC-001 | main交换SA/SB；UI输入队列将重活迁移至主循环，保留原页事件语义 |
| DES-002 | REQ-002 / AC-002 | ADC健康快照、统一启动换算、8点均值；纯C++四点校验、映射与记录编解码 |
| DES-003 | REQ-003 / AC-003 | EEPROM2480～2501显式小端记录、版本/CRC/读回；12字符密匙边界；成功后原子发布模型 |
| DES-004 | REQ-004 / AC-004 | PWM拥有校准/冷却状态、请求与输出，停止锁存；MIOT所有控制入口互斥；限幅与安全监督 |
| DES-005 | REQ-005 / AC-005 | 菜单7非阻塞状态机、固定容量30秒窗口、输入配对与停热后保存，旧路径完整移除 |
| DES-006 | REQ-006 / AC-006 | 分离主机行为验证/固件编译与实物电流、波形、测温和回流验收，不伪造硬件证据 |

## 组件、接口与同步
- `TempCalibration.h/.cpp`：无Arduino依赖，`TempCalibData`包含4个float raw、4个uint16 real；前缀校验、插值、22字节编解码，量化后再次校验。
- ADC新增 `snapshot()`、`set_calibration()`、`clear_calibration()`、`has_calibration()`、`calibrate_temp()`。`TempSample`包含raw_temp、instant_temp、calibrated_temp、sampled_at、sequence、healthy、ready；快照与模型均在短临界区复制。采样失败不能刷新有效时间或以旧值假装健康。
- PWM新增 `start_calibration()`、`set_calibration_point()`、`calibration_heartbeat()`、`request_calibration_stop()`、`calibration_status()`、`calibration_locked()`、`calibration_active()`、`calibration_can_save()`。终止请求仅锁存，输出线程执行停热后才允许保存。停止原因包含完成、取消、远程关闭、传感器、超温、采样/心跳/点/会话超时。
- 校准期间UI只提交请求；加热/风扇写入由PWM线程执行，避免半更新状态及旧回调重开输出。回调与UI之间使用短临界区或无锁原子事件；禁止在持有自旋临界区时执行analogWrite、OLED、Flash或等待。
- UI队列固定容量；中止通道独立锁存，不受队列满或唤醒吞键影响。校准记录仅在确认完成、输出归零后由主循环保存；模型发布后立即更新当前测温快照。
- `SAVING`中的同步Flash操作不可撤销；加热已为0。其他终止/故障优先于完成，候选模型不能参与控制。

## 数据、边界与兼容
22字节布局与CRC-16/CCITT-FALSE完全沿用批准计划。原参数地址不迁移；标定缺失不触发整机初始化；普通Flash写延后至活动校准之外。版本错误、CRC错误、几何错误均禁用映射；运行时保存失败保留旧内存，掉电不保证旧记录保留。工厂复位清除模型。回滚旧固件不再使用新增记录，原参数保持兼容。

校准230℃限温、250ms心跳、2500ms采样年龄、10分钟每点、30分钟会话、50℃以下连续10秒释放冷却锁；按无符号时间差处理回绕。四点raw/real为0～230℃、raw间距≥10℃、real间距≥5℃、斜率0.25～4；P0双温10～40℃且差≤10℃。标定映射越出工程范围0～400℃报告异常，不回绕。未标定有效温度保留原截断语义。

## 验证策略
| 验收 | 软件验证 | 硬件场景 |
| --- | --- | --- |
| AC-001 | 编译、事件主循环路径烟测 | 实际正反旋转、加速、按键与唤醒 |
| AC-002 | 编译实际纯C++模型与ADC代码，断言公式、异常及采样健康边界 | 对照参考温度 |
| AC-003 | 实际记录编解码与EEPROM代码的隔离故障注入，模拟commit/读回失败 | 重启、提交掉电、普通参数往返 |
| AC-004 | 实际PWM代码的时钟/采样/输出隔离注入，验证时限、锁存、限幅与冷却 | 断负载观测HEB/FAN波形、再受限通电测电流 |
| AC-005 | 实际稳定窗口/状态机的定向时间驱动，检查失稳与候选/保存转移 | OLED、热机拒绝、长按中止与固定测点输入 |
| AC-006 | `pio run -e esp32-c3-devkitm-1`只证明编译 | 独立限温与实测条件下完成计划AC6全部场景 |

永久测试仅针对消费者可见数值、状态、安全边界；不增加源码文字匹配或mock转发断言。全部编辑结束统一运行定向验证与固件编译；硬件不能由模拟替代。
